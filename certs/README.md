# Сертификат для GigaChat

Серверы GigaChat подписаны сертификатом НУЦ Минцифры (Russian Trusted Root CA),
которого нет в стандартных хранилищах. Скачайте корневой сертификат с Госуслуг
(раздел «Сертификаты НУЦ Минцифры») в формате PEM и сохраните здесь как
`russian_trusted_root_ca.pem`. Путь задаётся переменной `GIGACHAT_CA_BUNDLE`.

Это публичный сертификат, его можно хранить в репозитории.
